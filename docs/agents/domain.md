# Domain docs

## Before exploring

Read `CONTEXT.md`, or `CONTEXT-MAP.md` if it exists, plus relevant ADRs in `docs/adr/`.
If they do not exist, proceed silently.

## Layout

This is a single-context repository.
Use a root `CONTEXT.md` for the glossary and `docs/adr/` for architecture decisions.
Create either only when a real term or decision has been resolved.

## Vocabulary

Use terms defined in `CONTEXT.md` consistently.
Flag contradictions with an existing ADR instead of silently overriding it.
